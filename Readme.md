# Stage I - Asylum Demon
- All data on disk i.e. persistent 😉
- CRUD Operations + Toggle for Todos


## Endpoints
GET/POST / => Get all todos and post todos
GET/PUT/DEL /:id => todo with id
PUT /:id/toggle => mark as done or mark as not done.
